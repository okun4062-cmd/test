# Азбука гжельской росписи

Тренажёр гжельской росписи, который работает прямо в браузере, без установки.

- **Азбука** — 10 элементов, от капли до розана: описание, шаги техники и анимация того, как пишется каждый мазок.
- **Мастерская** — рисование кистью по контуру на тарелке. Ширина мазка зависит от нажима и скорости, есть мазок с тенью. Рядом показан образец. Проверка оценивает форму и технику и объясняет ошибки по каждому мазку.
- **Конструктор узора** — собирайте композицию из элементов на тарелке: симметрия, зеркало, кайма, свободная кисть.
- **Мои узоры** — галерея сохранённых работ.

## Запуск

Откройте `index.html` в браузере. Если включить GitHub Pages (Settings → Pages → Deploy from branch → `main`), приложение будет доступно по ссылке https://okun4062-cmd.github.io/test/gzhel/

Прогресс и узоры сохраняются в браузере (localStorage).
